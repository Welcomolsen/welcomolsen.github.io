# WORA Tech

Site vitrine WORA Tech, publié avec GitHub Pages sur https://wora-tech.github.io/.

- `index.html` : page d'accueil
- `confidentialite.html`, `conditions.html` : pages légales
- `404.html` : page d'erreur personnalisée
- `assets/css/site.css`, `assets/js/site.js` : styles et scripts communs (formulaire, bandeau de consentement, statistiques GoatCounter)
- `assets/img/` : images en WebP, `assets/fonts/` : police Plus Jakarta Sans hébergée sur le site
- `sitemap.xml`, `robots.txt`, `site.webmanifest`

Aucune clé ni aucun secret ne doit être placé dans ce dépôt : tout ce qui est ici est public.
